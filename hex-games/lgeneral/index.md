LGeneral is a remake of the DOS game [Panzer General](
https://en.wikipedia.org/wiki/Panzer_General). It is a part of
[lgames](https://lgames.sourceforge.io/). This is an attempt to make a
browser version.

**[Work in Progress]** Only basic maps are implemented

Please read more on [github](
https://github.com/uablrek/hex-games/blob/main/lgeneral/README.md)

The maps are draggable, but not scrollable. After you have loaded a
map (map03/Norway is default), edit the URL in your browser manually,
and reload, to show other maps, `map01-map38` are available.

Keys:
* `h` - Toggle the hex grid
* `c` - Clear map
* `m` - Mud map
* `s` - Snow map

* **[Maps](test-map.html?map=map03)** - Check out the maps
* **[Units](test-units.html)** - List units
