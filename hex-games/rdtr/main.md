# Rise and Decline of the Third Reich - Game

This is a browser version of the board game [Rise and Decline of the
Third Reich](
https://boardgamegeek.com/boardgame/1563/rise-and-decline-of-the-third-reich)
by Avalon Hill. It is not ready, Solitarie play may work, but
sequences are not finished. Only the 1939/Campaign scenario is
implemented.

Please read more on [github](
https://github.com/uablrek/hex-games/blob/main/rdtr/README.md).
